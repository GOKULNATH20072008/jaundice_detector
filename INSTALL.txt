# How to Install & Run

This project detects jaundice from an eye photo using a fine-tuned ResNet18.
Build for Windows with Python 3.14.

## 1. Prerequisites

- Python 3.14+ installed on your machine (with `pip`).
- Git (optional, only if cloning from a repo).

## 2. Set up a virtual environment

Open PowerShell / Command Prompt inside this folder and run:

```
py -m venv .venv
.venv\Scripts\activate
```

You should now see `(.venv)` at the start of your prompt.

## 3. Install dependencies (GPU / CPU)

### CPU-only (recommended for most laptops)

Torch is large, so install it first from the CPU index, then the rest:

```
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
```

### If you have an NVIDIA GPU

```
pip install torch torchvision
pip install -r requirements.txt
```

Note: `requirements.txt` contains plain `torch`/`torchvision` versions; the
CPU versions installed earlier are shown as `+cpu` in `pip freeze` and are
handled by the separate CPU-index install above.

## 4. Create the dataset (optional)

The dataset folders may already exist. If not:

```
python prepare_jaundice.py
```

This downloads the Hugging Face `Bleachcarte/Jaundice_Dataset`, sorts images
into `jaundice_dataset\jaundice_eye` and `jaundice_dataset\healthy_eye`.

## 5. Train the model (optional)

If `outputs\model_jaundice.pth` does not exist yet (about 5 minutes on CPU):

```
python train_jaundice.py
```

Artifacts written to `outputs\`:
- `model_jaundice.pth`  -> trained weights
- `label_map.json`       -> class-to-name mapping
- `training_curves.png`  -> loss/accuracy plot
- `confusion_matrix.png` -> confusion matrix
- `classification_report.txt`

## 6. Run the web app

```
python app.py
```

Open your browser at: **http://127.0.0.1:5000**

Upload an eye photo, press **Analyze**, and the app returns HEALTHY or
JAUNDICE DETECTED with a confidence score.

## 7. CLI prediction (optional)

Predict a single image from the command line:

```
python predict_jaundice.py path\to\eye_photo.jpg
```

## Troubleshooting

- **`ModuleNotFoundError`**: the venv is not active or dependencies are missing.
  Run `.venv\Scripts\activate` then `pip install -r requirements.txt`.
- **Port already in use**: change the port in the last line of `app.py`.
- **Slow first start**: the first run downloads the ImageNet weights for
  ResNet18 (~45 MB) into the torch cache.
